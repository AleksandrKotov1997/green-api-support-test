# Проверка задания

Дата: 5 октября 2026 года.

## Требования

| Требование | Результат |
| --- | --- |
| Четыре метода GREEN-API | Реализованы `getSettings`, `getStateInstance`, `sendMessage`, `sendFileByUrl` |
| Параметры подключения | Поля `idInstance` и `ApiTokenInstance`; токен скрыт |
| Ответ только для чтения | Отдельный `textarea` с атрибутом `readonly` |
| Макет | Параметры и методы слева, ответ справа; порядок блоков соответствует ТЗ |
| Исходники на GitHub | Отдельный репозиторий `AleksandrKotov1997/green-api-support-test` |
| Страница в Интернете | Vercel: `https://green-api-support-test.vercel.app/` |

## Реальные запросы

Проверка выполнена через интерфейс страницы с настоящим авторизованным WhatsApp-инстансом на тарифе Developer. Параметры подключения в репозиторий не включены.

| Метод | Ответ API | Проверка результата |
| --- | --- | --- |
| `getSettings` | HTTP 200, JSON настроек | `incomingWebhook: "yes"`, включено получение входящих сообщений и файлов |
| `getStateInstance` | HTTP 200 | `stateInstance: "authorized"` |
| `sendMessage` | HTTP 200, `idMessage` | Получатель подтвердил появление текста «Проверка GREEN-API: sendMessage» в WhatsApp |
| `sendFileByUrl` | HTTP 200, `idMessage` | Получатель подтвердил появление тестовой картинки в WhatsApp |

Получателем в итоговой проверке был WhatsApp-аккаунт, подключённый к инстансу, то есть чат «Сообщение себе». Приём результата API и фактическое получение сообщения проверены отдельно: `idMessage` сам по себе не подтверждает доставку.

## Автоматические проверки

`npm test`: 15 проверок, 15 успешных, без пропусков.

Проверены формат HTTP-запросов, JSON-тела обоих методов отправки, сохранение ошибочных ответов, ответы без JSON, таймаут, отсутствие автоматического повтора и утечки токена в сообщении сетевой ошибки. Проверены параметры подключения, номера, пустые сообщения, предел 20 000 символов, сохранение переносов и emoji, ссылки и определение имени файла.

## Проверка интерфейса

- Четыре кнопки методов доступны; поле ответа имеет `readonly`.
- Ошибка ввода отображается до запроса, выделяет поле и переводит в него фокус.
- Все кнопки блокируются на время запроса и становятся доступны после ответа.
- На ширине 1200 пикселей отображается двухколоночный макет.
- На ширине 390 пикселей контент помещается без горизонтальной прокрутки, ответ расположен под формами.

## Проверка публикации

Публичный адрес Vercel открывается без входа в аккаунт. HTML, стили, значок вкладки и три JavaScript-модуля возвращают HTTP 200 и совпадают с исходниками проекта. На опубликованной странице `getStateInstance` вернул HTTP 200 и `authorized`, а `getSettings` — HTTP 200 и `incomingWebhook: "yes"`. После перезагрузки поля подключения пустые.

В настройках проекта Vercel подключён GitHub-репозиторий `AleksandrKotov1997/green-api-support-test`. Production-ветка — `main`.
